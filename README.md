# MarketFlow

Marketplace multi-vendedor. Fase 1 en JavaScript, sin TypeScript.

## Carpetas

- `apps/api` — API Fastify (Paso 4)
- `apps/web` — frontend Next.js (Paso 12)
- `packages/db` — Prisma y PostgreSQL (Paso 5)
- `packages/contracts` — esquemas Zod compartidos
- `packages/config` — configuración compartida
- `docs/` — Parte 1 (fuente de verdad)
- `sandbox/` — ejercicios del Paso 2, no es la aplicación
